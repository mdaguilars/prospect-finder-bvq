# Baseline v1 — Regresión Logística

## 1. Objetivo

El objetivo de este experimento es establecer un primer modelo de referencia para el proyecto Prospect Finder BVQ.

El modelo busca estimar y priorizar empresas ecuatorianas que podrían convertirse en emisores del mercado de valores dentro de los siguientes 24 meses.

Este modelo constituye un **baseline interpretable** contra el cual se compararán posteriormente modelos de mayor complejidad.
